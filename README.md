

\# Gestor de tareas — Reto 2 UVEG



\## Descripción

Aplicación web desarrollada como proyecto académico para el módulo Despliegue de aplicaciones web y móviles v2, correspondiente al Reto 2: Prepara y lanza tu aplicación web.



La aplicación permite agregar tareas, marcarlas como completadas, eliminarlas y limpiar las tareas completadas.



\## Tecnologías utilizadas

\- HTML5

\- CSS3

\- JavaScript

\- Git y GitHub



\## Estructura del proyecto

\- `index.html`: página principal.

\- `css/styles.css`: hoja de estilos original.

\- `css/styles.min.css`: hoja de estilos minificada.

\- `js/app.js`: lógica JavaScript original.

\- `js/app.min.js`: JavaScript minificado.

\- `img/universidad-uveg.jpg`: imagen institucional.



\## Preparación y empaquetado

Los archivos se organizaron en carpetas para facilitar su mantenimiento. Se generaron versiones minificadas de CSS y JavaScript y se creó un paquete ZIP con los archivos necesarios para la aplicación.



\## Ejecución

Abre `index.html` en un navegador para probar la aplicación localmente.



\## Despliegue

La configuración del servidor web Apache o Nginx se documentará una vez realizada y verificada.
